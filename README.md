# Places
A Next.js/React.js web app for finding, getting directions to, and liking places near you. 

## Features
- Search with autocomplete
- Interactive map for viewing directions
- Search result, liked, and viewed feeds
- Passwordless authentication using Magic Auth and JWTs
- Protected routes using Next.js Middleware
- RESTful interface backend for session, place, and user data
- GraphQL API for querying user data from PostgreSQL database (Hasura)
- Light / dark mode
- Skeleton loading

## Implemented using:
- Typescript
- Next.js/React.js
- Material UI
- Redux Toolkit
- GraphQL + PostgreSQL (Hasura)
- The Google Maps Platform
- Magic Auth
